# EvolveWP ClientJourney

**CRM, proposals, and client portal for the EvolveWP ecosystem.**

Built by [FifeCIC](https://fifecic.scot) | Part of the [EvolveWP Ecosystem](https://evolvewp.dev)

---

## Overview

EvolveWP ClientJourney manages the full client lifecycle within WordPress —
from initial enquiry through proposals, phased agreements, digital signatures,
payments, and an ongoing client portal.

**Requires:** [EvolveWP Core](https://github.com/FifeCIC/EvolveWP.Core)

## Planned Features

- Client onboarding wizard
- Phased agreement system with digital signatures
- Stripe payment integration
- Client portal (frontend)
- Proposal templates and tracking
- CRM contact management

## Installation

1. Install and activate [EvolveWP Core](https://github.com/FifeCIC/EvolveWP.Core)
2. Upload `EvolveWPClientJourney` to `/wp-content/plugins/`
3. Activate via WordPress Admin → Plugins

## Requirements

- WordPress 5.6+
- PHP 7.4+
- EvolveWP Core (required dependency)
